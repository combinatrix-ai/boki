# Agent instructions

## Language

- Write everything that lands in this repository in English: code, comments, docstrings, row labels, plan headers, READMEs, docs, research notes, commit messages, and PR descriptions.
- Talk to the user in the user's language.
- Japanese text may stay only where it must match a source workbook verbatim (a sheet name or cell label used to locate data) or is quoted as source evidence. Put an English gloss next to it.
