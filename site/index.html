plan.pyimport boki as b from boki.lib import compound from boki.units import USD, year m = b.Model("Widget Co", start="2027-01", periods=5, step=year) co = m.entity("Widget Co", standard=b.USGAAP, currency=USD) co.bs.opening(cash=20e6 * USD) growth = m.input("Revenue growth", 0.25) sales = co.pl.revenue("Product sales", compound(40e6 * USD, growth)) co.pl.cogs("Cost of sales", 0.45 * sales) co.pl.sga("Operating expenses", 6e6 * USD + 0.15 * sales) co.bs.fixed_asset("Plant", 30e6 * USD, at=0, life=10 * year) co.bs.loan("Term loan", draw={0: 25e6 * USD}, rate=0.07, repay=5e6 * USD) co.pl.income_tax("Income taxes", rate=0.21, base=co.pl.pretax_income) m.render().to_excel("widget.xlsx", money="$mm")

How it works

Code where logic belongs. Excel where analysts work.

Spreadsheet models cannot be diffed, tested or reviewed, and their hardest parts — circular references, macro-pasted values, broken links — are the least visible. boki keeps the model in Python and compiles a workbook you can trust.

Every number is a live formula — traceable end to end.

Every assumption lives once on Inputs in blue, flows cleanly through statement formulas in black, and ties out automatically on Checks. No hardcoded overrides, no pasted macro outputs.

  • Live recalc in Excel & LibreOffice: change a growth rate, scenario index, or sensitivity header and the whole workbook updates.
  • Independent formula audit: every formula cell in boki's test suite is recalculated by an independent engine and compared against Python.

Built for AI agents. Mistakes cannot get through.

Writing spreadsheets directly via cell coordinates is brittle for humans and catastrophic for LLMs. With boki, an agent writes concise Python and gets immediate, actionable diagnostics whenever accounting or units break.

  • Perturbation-verified rewrites: b.block(..., verify="perturb") checks Base, every scenario, and random input perturbations before emitting concise banker =SUM(...) formulas.
  • Code reviewable in Git: diff assumptions, run pytest in CI, and pin board-approved numbers with b.expect.

The accounting is done for you

Write revenue, payment terms, fixed assets and loans. boki books the double entries, depreciation, interest and indirect cash flow.

co.pl.revenue("Sales", 120 * USD, settle=b.delay(1))
co.bs.fixed_asset("Oven", 60 * USD, at=0, life=3 * year)
print(m.render().cf(co, method="indirect"))

Explicit solving, zero hidden loops

Debt sculpting, interest during construction and goal seeks are solved explicitly with m.solve. Unintended loops stop immediately.

debt = m.unknown("Debt", unit=USD.dims)
idc  = m.series("IDC", 0.08 * debt)
m.solve(debt, debt == 1_000 * USD + idc)  # 1,086.96

Proof-carrying Excel blocks

Emit clean banker subtotals without sacrificing auditability — boki proves your Excel override equals the ledger before writing.

b.block(co.cf.operating, [
    co.pl.net_income, depreciation, change_in_nwc,
], label="Cash flow from operations", verify="perturb")

Diff, test, and pin board numbers

Stamp out one model per site or vintage, sweep scenarios in a loop, and fail CI if a change moves signed-off numbers.

b.expect(m.render(), {
    co.pl.net_income: [7.9e6, 7.3e6, 11.5e6, 16.7e6, 23.2e6]
}, rel=0.01)
